# ClinicFlow UI/UX Skill

## Scope

This skill ONLY handles:
- UI refactors
- UX improvements
- layout cleanup
- spacing consistency
- responsive polish
- component consistency
- visual hierarchy improvements

Global design rules and visual system are defined in:
- AGENTS.md

Do NOT redefine styles here.

---

# Restrictions

DO NOT modify:
- business logic
- services
- API integrations
- RxJS logic
- routing
- authentication
- permissions
- backend contracts
- validations
- workflows

Only improve:
- visual consistency
- usability
- responsiveness
- operational clarity
- frontend UX polish

---

# Operational Priorities

Prioritize:
1. lower cognitive load
2. cleaner layouts
3. faster visual scanning
4. fewer unnecessary elements
5. operational clarity
6. responsive behavior
7. onboarding simplicity

---

# Refactor Rules

Before creating:
- components
- layouts
- wrappers
- styles

First:
- reuse existing structures
- extend existing components
- preserve current architecture

Avoid:
- unnecessary rewrites
- large refactors
- introducing new abstractions
- overengineering

---

# UX Expectations

The interface should:
- feel lightweight
- feel operational
- reduce friction
- guide attention correctly
- remain visually calm

Always optimize for:
- speed perception
- readability
- workflow continuity
- simplicity

---

# Agent Behavior

Make:
- surgical modifications
- minimal safe changes
- incremental improvements

Do NOT:
- redesign the entire app
- change architecture
- introduce experimental UI patterns
- modify functionality
